# Usage guide

Just ask for what you want to build. The skill activates on requests about websites, apps, UI, plans, Claude skills, MCP servers or plugins, or when you mention OwnlyPlans.

## Prompts to try
- Find the best UI elements for a modern SaaS dashboard.
- Create a complete development roadmap for my startup.
- Find Claude skills that improve my coding workflow.
- Recommend MCP servers for my project.
- Help me build a responsive landing page using OwnlyPlans resources.
- Find the best resources for building an AI application.

## What you get back
For each recommendation: a direct link, what it does, why it fits your request, requirements, the install command from the item itself, steps, limits and a next action. Up to three tiers: **Best match**, **Alternative**, **Advanced option**.

## How to get better answers
- Name your stack ("React and Tailwind", "plain HTML", "WordPress").
- Say your level ("I'm new to this" gets plain language and one command at a time).
- Say what must be true ("must work on phones", "no build step").
- Ask Claude to "implement it" when you want it to go beyond recommending.

## Guided implementation
Say "build it with those" and Claude walks the plan or components step by step, confirms before running installs, runs your build or tests and reports the real result.

## What Claude will not do
- Invent items, links or install commands.
- Claim something was installed or tested when it was not.
- Ask for passwords or tokens. Do not paste real secrets into prompts.
