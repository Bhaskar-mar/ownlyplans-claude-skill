# Security policy

## Scope
This repository contains instructions, documentation and a small Python script that makes read-only HTTPS requests to the OwnlyPlans MCP endpoint. It stores no credentials.

## Reporting a vulnerability
Please do not open a public issue for security problems. Use GitHub's private vulnerability reporting on this repository (Security tab), or contact the OwnlyPlans team through https://ownlyplans.com/. Include what you found and how to reproduce it.

## Handling third-party resources
Resources on OwnlyPlans are written by community members. The skill tells Claude to read skills, MCP configs and install commands before recommending them, and never to ask for passwords or tokens. Users should do the same before running anything.
