# Changelog

All notable changes are listed here. Versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-10
### Added
- `SKILL.md` workflow: intent detection, access routes, search, verification, three-tier recommendations, guided implementation, honest reporting.
- References for overview, categories, discovery, MCP integration, quality checks, recommendation format, implementation and troubleshooting.
- `scripts/ownlyplans_mcp.py`: standard-library client for the OwnlyPlans MCP endpoint.
- `scripts/validate_skill.py` and `scripts/test_skill.py` (mock-server tests).
- Examples, documentation, SVG banner, logo and diagrams.
- GitHub Actions validation workflow, issue and pull request templates.
