# Example: portfolio website

> Illustrative.

**User:** Help me implement a portfolio site. I want a gallery and a strong hero.

**Claude:** searches components for `gallery`, `image`, `carousel`, `hero`, `button`; verifies; recommends:

- **Best match:** *Image Viewer Lightbox* (https://ownlyplans.com/bhaskar/image-viewer-lightbox/) for the gallery.
- **Alternative:** *3D Cylinder Carousel* (https://ownlyplans.com/bhaskar/3d-cylinder-carousel/) for a more playful showcase.
- **Advanced:** *Sheen Outline Buttons* (https://ownlyplans.com/bhaskar/sheen-outline-buttons/) for calls to action.

Then, in guided mode: builds the page, swaps the demo gradients for the user's images, runs a check at phone width, and reports exactly what it ran. Where an item's own claims could not be reproduced, it says so.
