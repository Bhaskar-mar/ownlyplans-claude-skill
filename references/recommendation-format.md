# Recommendation format

Use this for each recommended item. Keep it tight.

```
### <Tier>: <Title> (<kind>)
Link: <url>
What it does: <one or two sentences from the item>
Why it fits: <tied to the user's stated need>
Requirements: <stack, dependencies, accounts - or "not stated">
Install: <exact command from the item's install field, or "copy the code from the page">
Steps: 1) ... 2) ... 3) ...
Limits: <what it does not cover; unverified facts>
Next: <one concrete action>
```

Tiers:
1. **Best match** - fits the need most directly with the least setup.
2. **Alternative** - a different approach or style that also works.
3. **Advanced option** - more powerful or flexible, with more setup. Skip if none.

End with a short "what I verified" line, for example: "Verified: fetched all three items via MCP. Not verified: runtime behaviour in your project."
