# Example conversations

Full walkthroughs are in `examples/`. Short forms:

**"Find the best UI elements for a modern SaaS dashboard."**
Claude searches components for `dashboard`, `sidebar`, `table`, `chart`, verifies the finalists, then answers with Best match, Alternative and Advanced option, each with link, fit, install or copy instructions and limits.

**"Create a complete development roadmap for my startup."**
Claude asks one question about the product if unclear, searches plans, picks the closest, reads its steps and returns a phased roadmap, labelling which steps come from an OwnlyPlans plan and which are Claude's own.

**"Find Claude skills that improve my coding workflow."**
Claude searches skills (`review`, `migration`, `accessibility`, `testing`), reads each `SKILL.md`, and recommends the few that match, with the install command and a note on what each one changes.

**"Recommend MCP servers for my project."**
Claude asks or infers the data and services involved, searches `mcp`, and explains each server's actual capabilities and credentials from its listing.

**"Help me build a responsive landing page using OwnlyPlans resources."**
Claude finds a hero, navigation, pricing, FAQ and footer components, checks fit, assembles the page, runs it and checks it at phone width.

**"Find the best resources for building an AI application."**
Claude searches plans, MCP servers and skills for the app type, and recommends a small stack of items with the reason for each.
